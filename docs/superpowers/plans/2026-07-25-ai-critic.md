# AI Critic and Detective Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an optional blind OpenAI gallery critic and non-scoring detective to both game modes without changing human voting, scoring, offline play, or anti-cheat boundaries.

**Architecture:** Extend the shared reducer with deterministic critic request/result events, then use a focused Cloudflare Worker module to call the OpenAI Responses API with a wordless PNG and strict JSON Schema. Online rooms coordinate one request through the existing Durable Object; local games use a rate-limited stateless endpoint. Both modes render the same verdict screen after the outcome is settled and persist sanitized verdicts into the existing archive.

**Tech Stack:** TypeScript, React 19, Vite, Vitest, Cloudflare Workers and Durable Objects, Cloudflare Rate Limiting binding, OpenAI Responses API (`gpt-5.6-luna`, image input, Structured Outputs), browser Canvas API.

## Global Constraints

- Human ballots and official scoring remain unchanged; AI detective picks never count.
- Never show a ready AI verdict before `round.outcome` is non-null.
- Never send the real word, fake identity, ballots, score, outcome, or house words to OpenAI.
- Reuse the existing `OPENAI_API_KEY` from the ignored `.env`; never expose, print, rewrite, or prefix it with `VITE_`.
- Production reads `OPENAI_API_KEY` as a Wrangler secret; the browser bundle receives no API credentials.
- Default settings are `aiCritic: true`, `aiDetective: false`, and `aiTone: "witty"`.
- Supported tones are exactly `"witty"`, `"savage"`, and `"absurd"`.
- Use one 512 by 512 PNG with `detail: "low"` and one provider request per online round.
- Use `reasoning: { effort: "low" }` with the `gpt-5.6-luna` default to keep reveal latency bounded.
- The pass-one-phone game remains fully playable offline and never retries AI requests automatically.
- AI output roasts visible artwork decisions, never a player's identity, appearance, intelligence, disability, or personal worth.
- No new runtime dependency is required for the OpenAI call; use the Worker runtime's `fetch`.

export async function criticPng(strokes: Stroke[]): Promise<Blob> {
