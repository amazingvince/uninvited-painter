# AI Post-Round Exhibition Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Luna 5.6's blind, snarky post-round verdict and GPT Image 2's automatic faithful real-world rendition to local and online games without changing human voting or blocking progression.

**Architecture:** Extend the deterministic shared reducer with one idempotent per-round AI job whose critic and rendition branches resolve independently. When voting starts, a client uploads one wordless 1024px PNG; a Cloudflare Workflow calls Luna and the GPT Image 2 edits endpoint concurrently, stores binary artwork in private R2, and returns sanitized results through room-owned or local job state. Both results stay redacted until the human outcome is public, then feed dedicated reveal screens, the final gallery, and permanent archives.

**Tech Stack:** TypeScript, React 19, Vite, Vitest, Cloudflare Workers, Durable Objects, Workflows, R2, KV, Cloudflare Rate Limiting, OpenAI Responses API (`gpt-5.6-luna`), OpenAI Image Edits API (`gpt-image-2`), browser Canvas API.

## Global Constraints

- Human ballots, fake-artist guessing, scoring, winners, and round progression remain unchanged.
- AI work starts only when a non-voided round first reaches `voting`.
- Luna never receives the intended word, fake identity, ballots, scores, outcome, house words, or player display names.
- GPT Image 2 receives only the wordless drawing, authoritative intended word, and fixed faithfulness instructions.
- Never expose a critic result, rendition ID, rendition URL, or secret word before `round.outcome` is non-null.
- The AI detective pick is ceremonial and never counts toward the human tally.
- Default settings are `aiCritic: true`, `aiDetective: false`, and `aiTone: "witty"`.
- GPT Image 2 rendition runs automatically whenever `aiCritic || aiDetective`.
- Supported tones are exactly `"witty"`, `"savage"`, and `"absurd"`.
- Use `gpt-5.6-luna` with `reasoning: { effort: "low" }` and strict structured output.
- Use `gpt-image-2` through `/v1/images/edits`, 1024 by 1024, medium quality, JPEG, and approximately 85% compression.
- Omit `input_fidelity`; GPT Image 2 applies high-fidelity reference handling automatically.
- Preserve odd proportions, positions, directions, silhouettes, colors, overlaps, negative space, and accidental-looking details.
- Reuse the existing ignored `.env` `OPENAI_API_KEY` locally. Never print, rewrite, expose, or prefix it with `VITE_`.
- Production reads `OPENAI_API_KEY` as a Wrangler secret.
- Player names stay out of provider inputs; the UI resolves validated player IDs to names.
- AI output may roast visible artwork choices, never identity, appearance, intelligence, disability, or personal worth.
- Critic and rendition branches fail independently and never block voting, reveal, next round, close, save, or archive actions.
- Never blindly retry an ambiguous image-generation failure.
- A refresh, reconnect, or duplicate upload reuses the existing round job and cannot buy a second intended generation.
- Generated bytes live in private R2; shared state and KV metadata hold only bounded JSON and opaque IDs.
- Previously saved rooms and published archives remain valid.
- No OpenAI SDK runtime dependency is required; use the Worker runtime's `fetch`.
